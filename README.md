# SENTRY-RAG: Robust Retrieval for Question Answering

**Secure Machine Learning project, Toronto Metropolitan University**

## The problem
Retrieval-augmented generation (RAG) systems trust the documents they retrieve. An attacker can hide instructions inside a document (indirect prompt injection) or slip poisoned documents into the index to steer the answers.

## What SENTRY-RAG does
Measures how vulnerable a standard RAG pipeline is to these attacks and tests a retrieval-side defense that reduces the influence of suspicious content before it reaches the language model.

## Outcome
On a multi-hop question-answering benchmark, the system beat a strong re-ranking baseline on QA accuracy and lowered prompt-injection risk.
